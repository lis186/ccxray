## How this repo wants work done

- **Second review is mandatory before merge.** codex is out on account quota; **use grok** (`grok -p "$(cat prompt)" --output-format json < /dev/null`, then read `.text`; `stopReason: cancelled` means it hit a turn limit — constrain the prompt). The merge hook accepts `grok gate clean` in the PR body; anything that merely names the reviewer does not.
- **Differential evidence, not assertions**: every behavioural change needs a test that FAILS on the old code and passes on the new (`git stash push -- <paths>` then `--test-name-pattern`). Guards that pass on both sides are fine — label them as guards.
