## 節奏表(總長 10:00)

高橋流的節奏感 = **快慢交錯**。單詞頁用機關槍速度連發(1–2 秒一頁),
關鍵頁(紅字、青字)停下來,留 3–5 秒白。以下是每幕的時間預算與講法:

| 幕 | 英雄旅程 | 時間 | 節奏與講法 |
|----|----------|------|------------|
| 序幕 | 平凡世界 | 0:00–0:40 | 平穩、親切。「你、每天、和 AI」三連發要快,「但是——」故意拖長,吊住全場 |
| 第一幕 | 冒險的召喚 | 0:40–2:00 | 連珠炮拋問題,一題比一題快。「你不知道」放慢,「帳單知道」重擊+停 3 秒(全場第一個笑點/痛點)|
| 第二幕 | 拒絕召喚 | 2:00–2:40 | 模仿觀眾的自我安慰,語氣輕鬆。「直到——」轉折收笑,「燒掉整晚預算」壓低聲音 |

## 設計原則

- **一頁一個念頭**:超過 7 個字就該懷疑要不要拆頁。
- **顏色即語法**:紅 = 痛點,青 = ccxray / 轉折,綠 = 解脫,灰 = 旁白;全場不需要圖表。
- **問答對仗**:第一幕的每個問題,第四、五幕逐一回收——聽眾自己會對上。
- **首尾呼應**:`npx ccxray claude` 出現兩次;第一次是神器,第二次是行動呼籲。
